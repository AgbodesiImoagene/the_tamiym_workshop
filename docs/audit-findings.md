# Audit Findings

All known issues surfaced by two rounds of business-logic and production-readiness audits.
Issues from Round 1 (orders / pricing / payouts / campaigns) were fixed in the first implementation pass — they are not listed here.

> **Status legend:** `OPEN` · `FIXED` · `WONTFIX` · `DEFERRED`

---

## CRITICAL

| #   | Status | Module   | File                               | Finding                                                                                                                                                                                                                                                                           |
| --- | ------ | -------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C-1 | FIXED  | Webhooks | `orders/webhooks.controller.ts:35` | Fallback `Buffer.from(JSON.stringify(req.body))` for HMAC verification is not bit-identical to the raw Paystack body. Requests that arrive without `rawBody` should be rejected outright, not re-serialised. Can silently break payment confirmation or allow spoofed signatures. |
