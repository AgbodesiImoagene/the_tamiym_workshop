\section{Deliverables}

This section defines the tangible outputs to be delivered as part of the project.
The deliverables are intended to provide a complete, usable, and deployable
platform that aligns with the agreed scope and design specifications.

\subsection{Primary Deliverables}

The following primary deliverables are included in the project:

\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Web Application}
    \begin{itemize}
        \item A fully functional, responsive web platform implementing the
        customer-facing website and authenticated user dashboard
        \item Implementation aligned with the approved design specifications
        and defined feature scope
    \end{itemize}

    \item \textbf{Design Workshop}
    \begin{itemize}
        \item Interactive customization experience for supported products
        \item Support for text, artwork uploads, color selection, and product
        view switching as defined in the designs
    \end{itemize}

    \item \textbf{Fundraising Module}
    \begin{itemize}
        \item Fundraiser creation and management functionality
        \item Customer-facing fundraiser pages and campaign tracking views
    \end{itemize}

    \item \textbf{Admin Dashboard}
    \begin{itemize}
        \item Administrative interfaces for order, product, inventory, and
        fundraising management
        \item Moderation tools and access-controlled administrative functionality
        \item Basic analytics and reporting dashboards as defined in scope
    \end{itemize}
\end{itemize}

\subsection{Supporting Deliverables}

The following supporting deliverables are also included:

\begin{itemize}[leftmargin=1.5em]
    \item Deployment-ready build of the application
    \item Basic configuration and setup documentation where applicable
    \item Access credentials or handover information required to operate the
    platform
\end{itemize}

\subsection{Exclusions}

The following items are not included as deliverables unless explicitly agreed in
writing:
\begin{itemize}[leftmargin=1.5em]
    \item Ongoing operational support or customer service
    \item Post-launch feature development beyond the agreed scope
    \item Advanced analytics, custom reporting, or data science deliverables
    \item Marketing materials or content creation beyond what is provided
    by the client
\end{itemize}
