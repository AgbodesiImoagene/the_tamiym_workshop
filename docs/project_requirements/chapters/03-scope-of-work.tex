\section{Scope of Work}

This section defines the functional scope of the project based on the approved
designs and agreed requirements. The scope is structured to clearly outline what
is included in the initial implementation and to set expectations around system
boundaries. The goal is to deliver a complete, usable product out-of-the-box (OOTB),
including essential administrative tools required to operate the platform.

\subsection{In-Scope Components}

The following components are included within the scope of this project:

\begin{itemize}[leftmargin=1.5em]

    \item \textbf{Public Website}
    \begin{itemize}
        \item Home, About, Products, and Fundraising informational pages
        \item Marketing content and calls-to-action aligned with the provided designs
    \end{itemize}

    \item \textbf{Customer Dashboard}
    \begin{itemize}
        \item Authenticated navigation (desktop and mobile views where applicable)
        \item Account profile management and settings (e.g., personal info, password, shipping details)
        \item Access to product browsing, design creation, orders, and fundraising sections
    \end{itemize}

    \item \textbf{Product Browsing}
    \begin{itemize}
        \item Product listing and filtering by category
        \item Product detail pages with supported size and color options
        \item Related products presentation where shown in the designs
    \end{itemize}

    \item \textbf{Design Workshop}
    \begin{itemize}
        \item Interactive design interface for customizing apparel
        \item Support for uploading artwork and adding text (as shown in the designs)
        \item Product color and size selection within the workshop experience
        \item Preview of front/back/sleeve views where applicable
        \item Save and share design actions (as defined in the designs)
    \end{itemize}

    \item \textbf{Checkout and Orders}
    \begin{itemize}
        \item Shipping information collection
        \item Payment method selection (as applicable to the target market and client requirements)
        \item Order confirmation/success states and post-purchase navigation
        \item Order history and order detail views (including order status progression where shown)
    \end{itemize}

    \item \textbf{Fundraising Features}
    \begin{itemize}
        \item Fundraiser creation workflow (e.g., select \& design, story, settings)
        \item Fundraiser configuration (organizer details, timeline/dates, payout configuration, delivery options)
        \item Customer-facing fundraiser links/pages for browsing and purchasing fundraiser items
        \item Fundraiser tracking views (campaign status, basic performance indicators where applicable)
    \end{itemize}

    \item \textbf{Admin Dashboard (Operational Tools)}
    \begin{itemize}
        \item \textbf{Order management:} view/search orders, update statuses, handle exceptions (e.g., cancellations/refunds where policy allows),
        and view order details
        \item \textbf{Product management:} create/update product listings, categories, pricing inputs, product availability controls
        \item \textbf{Inventory management:} track stock availability inputs where relevant, manage variants (size/color), and mark items as out-of-stock
        \item \textbf{Fundraiser administration:} view campaigns, approve/disable campaigns as needed, and handle basic organizer support workflows
        \item \textbf{Moderation:} basic controls to review and manage user-generated content (e.g., uploaded artwork/designs) and user accounts,
        including the ability to flag, restrict, or remove content based on agreed policies
        \item \textbf{Access control:} admin login and role-based permissions for administrative responsibilities
    \end{itemize}

    \item \textbf{Basic Analytics \& Reporting (OOTB)}
    \begin{itemize}
        \item Simple operational dashboards (e.g., orders placed over time, revenue summaries, campaign performance snapshots)
        \item Basic filtering (e.g., by date range, campaign, product)
        \item Export of key reports (e.g., CSV download) where appropriate
    \end{itemize}

\end{itemize}

\subsection{Out of Scope}

The following items are explicitly excluded from the initial scope unless
otherwise agreed in writing:

\begin{itemize}[leftmargin=1.5em]
    \item Native mobile applications (iOS/Android) beyond responsive web experiences
    \item Deep third-party logistics integrations (e.g., real-time courier tracking APIs) unless specified
    \item Advanced business intelligence (BI) and custom reporting pipelines beyond basic OOTB dashboards
    \item Complex warehouse management or multi-location inventory optimization
    \item Custom font licensing procurement and proprietary artwork creation (unless provided by the client)
    \item Post-launch marketing, SEO campaigns, or growth management services
\end{itemize}
